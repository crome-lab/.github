We develop, implement, and disseminate novel methods for improving medication
safety and health behaviors for vulnerable and underserved populations, while
training the next generation of researchers. Our work is community-engaged,
collaborative, and transdisciplinary, and it is built around partnership with
families, patients, clinicians, and community stakeholders.

## Why this organization exists

This is where the lab keeps the code behind its projects and papers. Games,
analyses, and tools all live here rather than on individual accounts, so the
work stays with the lab when people move on, and so anyone reading one of our
papers can see how the results were produced.

## How our repositories are organized

- **One repository per project, game, or paper.**
- **Two starting points.** Research and analysis projects start from
  [analysis-template](https://github.com/crome-lab/analysis-template). Games and
  applications start from
  [project-template](https://github.com/crome-lab/project-template).
- **Naming.** Lowercase, hyphens between words. Games use their own name
  (`crossroads`, `pedsmarxt`). Research repositories use a `study-` prefix
  (`study-colon-cancer-survival`).
- **No data in repositories, ever.** We work with human subjects data and
  protected health information. Code and documentation are versioned here.
  Data stays on approved secure storage and never touches GitHub.

## Research cores

Medication and vaping safety interventions · Game-based learning ·
Culturally-centered complementary and alternative medicine (C-CAM) ·
Cancer education and literacy · Cystic fibrosis and medication management
